# TangTang V4 五轮多角色审核计划

目标：每轮都遵循“审核 → 修复 → 回归测试 → 再审核”，连续五轮；任何 P0 不得进入下一轮。

## 角色
1. 系统架构师：边界、依赖、可演进性、旧系统兼容。
2. 隐私与儿童安全审查员：PRIVATE/FAMILY/PUBLIC、最小化、默认拒绝、数据生命周期。
3. AI/对话架构师：Context 最小充分、人格隔离、提示词边界、降级。
4. 家庭产品经理：9岁/12岁/成人/老人场景、主动打扰价值、误打扰。
5. macOS/IoT 工程师：launchd、音频、TTS、投影、离线与恢复。
6. 测试/QA：单测、集成、故障注入、回归、可观测性。
7. 安全工程师：secret、权限、日志、路径、注入和供应链风险。

## 每轮门禁
- P0：隐私泄露、越权、secret 泄露、不可恢复数据损坏 → 必须修复。
- P1：核心流程错误、生产路径错误、可靠性明显不足 → 原则上修复后再过轮。
- P2：体验、性能、可维护性 → 可记录后进入后续迭代。

## 五轮
### Round 1 基础正确性
审核 V4 Core 五模块；修复数据模型、异常、边界、导入、测试覆盖。
### Round 2 隐私与安全
从存储到 Context 全链路追踪；验证 PRIVATE 无绕过；secret/log/path 扫描。
### Round 3 家庭行为与产品
模拟六成员、主动提醒、静默、频控、unknown、冲突场景；减少恐怖/唠叨体验。
### Round 4 系统可靠性
断网、TTS失败、STT失败、投影断开、进程重启、重复事件、并发、launchd。
### Round 5 发布审查
全量回归、架构债务、性能、日志、文档、安装恢复；形成是否合并 main 的最终结论。

每轮输出：发现 → 风险等级 → 修复 → 新测试 → 回归结果 → 是否进入下一轮。不得以修改测试掩盖问题。
