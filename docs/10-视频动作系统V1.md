# 糖糖AI｜视频动作系统 V1

## 目标

投影端优先使用真正连续的短视频动作，而不是用单张PNG整体平移、缩放、旋转冒充动画。

## 目录

```text
assets/tangtang/video/
├── idle.webm
├── walk.webm
├── run.webm
├── happy.webm
├── curious.webm
├── caring.webm
├── encouraging.webm
├── sleepy.webm
├── sleeping.webm
├── wake.webm
└── welcome.webm
```

## 原则

- 每个动作独立文件，便于OpenClaw调用。
- 建议2～5秒，动作自然循环或有明确结束帧。
- 优先WebM；浏览器兼容需要时提供MP4 fallback。
- 视频必须保持糖糖统一形象、比例、视角和透明/背景规范。
- 视频是“表现层”，不承担业务判断。

## 动作调用

```json
{
  "action": "walk",
  "loop": true,
  "speed": 1.0
}
```

或：

```json
{
  "action": "caring",
  "loop": false,
  "message": "看了好久啦，要不要起来走两步？"
}
```

## 状态衔接

`wake → happy → idle`
`welcome → happy → idle`
`sleepy → sleeping`
`caring → idle`
`walk → idle`
`run → idle`

## 资源原则

不要一次加载所有视频。启动时只加载idle，其他动作按需预加载/缓存。长时间运行必须释放不用的媒体资源，避免内存增长。
