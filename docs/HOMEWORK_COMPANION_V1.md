# 糖糖作业管家 V1（开发中的本地优先方案）

## 目标闭环

1. 家长输入/上传老师布置的作业，按孩子、日期、科目整理成清单。
2. 生成可预览的每日作业纸，用户确认后由家庭 Mac 的 Epson 打印队列输出。
3. 孩子或家长用手机拍照，上传到家庭内网页面；照片默认留在 Mac 本机。
4. AI 对照作业清单检查可见页、题目覆盖、照片清晰度和疑似遗漏。
5. 结果分为“看起来已完成”“疑似遗漏”“照片模糊”“需要人工确认”，不直接把 AI 判断当作最终完成。
6. 复核后的未完成项可转成糖糖现有任务/提醒。

## 本次已提交的基础代码

- `core/homework/service.py`：本地作业清单、成员隔离、照片证据元数据、复核状态。
- `core/homework/printer.py`：macOS 打印队列查询；只允许打印生成目录内的 PDF；必须显式确认；不调用 shell。
- `tests/v4/test_homework_service.py`：成员隔离、路径安全、AI 不自动判定完成、打印确认等测试。

## 打印机接入原则

Epson 现已能稳定打印，因此优先复用家庭 Mac 已配置好的 macOS 打印队列，不另做 Epson 私有协议。macOS 支持通过 AirPrint/IPP 等系统打印机制接入兼容打印机；具体队列名称以本机 `lpstat -p` 返回为准。自动提交打印任务前必须有预览和明确确认。

## 照片与儿童隐私

- 原始照片存储和模型识别尚未接入；当前元数据服务不保存图像字节或完整 OCR 文本。
- 不默认把照片上传到第三方云服务；未来若使用云端视觉模型，必须有明确配置与家长知情选择。
- 仅允许已登记家庭成员查看自己的作业；跨成员共享必须由家长显式授权。
- AI 检查结果不自动标记“完成”，不把照片里识别出的儿童个人信息写入长期陪伴记忆。
- 需要设置照片保留期限、家长删除入口、上传大小限制、文件类型检查、随机文件名和访问令牌。

## 尚未完成（不可误称已上线）

- 作业照片安全落盘、图像方向修正、页数/题目覆盖识别。
- 生成打印预览 PDF 的实现与真实 Epson 队列验收。
- 视觉模型适配、失败降级和人工复核界面。
- 与现有任务提醒服务的正式联动。

## 验收顺序

1. 先跑 CI 单元测试。
2. 在 Mac 上只读取打印队列，不自动打印。
3. 生成一页测试清单，展示预览，家长确认后才打印。
4. 手机在同一家庭网络打开作业页面，上传一张测试图片。
5. 确认照片不出家庭本机（除非家长主动开启云识别），再验收 AI 结果和删除功能。
