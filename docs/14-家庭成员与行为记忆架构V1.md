# 糖糖家庭成员与行为记忆架构 V1.0

## 目标

糖糖不再只识别“主人”，而是建立家庭多人库。声音识别只负责回答“是谁”，行为记忆负责回答“这个人今天发生了什么、最近有什么变化”。

## 家庭成员模型

每个成员至少包含：

- `member_id`：稳定内部 ID，不使用姓名作为主键
- `display_name`：糖糖称呼
- `relation`：爷爷/奶奶/爸爸/妈妈/姐姐/弟弟等
- `age`：可选
- `profile`：儿童 PLAY、青少年 FRIEND、成人、长辈等
- `voiceprint_ref`：声纹引用；声纹原始数据不得进入 Git
- `permissions`：数据可见范围
- `preferences`：称呼、话题、提醒偏好

## 行为事件

统一采用事件模型：

```json
{
  "event_id": "evt_xxx",
  "member_id": "member_xxx",
  "timestamp": "2026-08-28T08:20:00+08:00",
  "type": "meal",
  "value": {"meal": "breakfast"},
  "source": "voice",
  "confidence": 0.91,
  "privacy": "private"
}
```

建议事件类型：

- `wake` 起床
- `sleep` 睡觉
- `meal` 吃饭
- `water` 喝水
- `exercise` 运动
- `screen` 屏幕/游戏
- `study` 学习
- `work` 工作
- `outdoor` 外出
- `home` 回家
- `chore` 家务
- `conversation` 对话
- `mood_signal` 情绪信号

## 三层记忆

### L1 今日记忆

记录当天发生的事件，用于当天陪伴。

### L2 近期趋势

基于 7～30 天事件形成趋势，例如“最近连续几天运动减少”。

### L3 稳定习惯

只有经过足够次数和时间验证的规律才能进入长期习惯，不能因为一次事件就改变人格判断。

## 重要原则

1. 声纹识别结果必须带置信度。
2. `unknown` 不得自动绑定到任何家庭成员。
3. 单次行为不能直接形成长期结论。
4. 儿童私人对话默认不进入家庭共享摘要。
5. 家长可配置可见范围，但糖糖不能诱导孩子隐瞒危险信息。
6. 所有行为记录默认本地优先；敏感数据不进入 GitHub。
7. 家庭成员可以被停用、重新训练声纹，而不是删除历史结构后重新建号。

## 糖糖的智能链路

```text
声音/环境事件
      ↓
身份识别
      ↓
成员 Profile
      ↓
记录行为事件
      ↓
读取今日记忆
      ↓
读取近期趋势
      ↓
判断是否值得打扰
      ↓
选择人格与话术
      ↓
选择动作/视频/声音
      ↓
执行并记录结果
```
