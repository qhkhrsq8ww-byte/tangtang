# 糖糖 V3 全面测试计划

版本：V1.0  
目标：让 OpenClaw 在客厅 Mac Air 上拉取 `main` 后，完成自动化测试、硬件测试、语音链路测试和家庭行为测试，并把结果反馈回来。

## 一、测试原则

1. **先自动化，后实机**：云端/Linux 先跑纯软件测试；Mac Air 再验证麦克风、音箱、投影、Safari。
2. **不把云端测试冒充实机测试**：Linux 没有客厅麦、蓝牙音箱和投影时，标记 `SKIP`，不能记为 PASS。
3. **测试不得污染真实家庭数据**：自动化测试必须使用临时 `TANGTANG_DATA_DIR`；不得提交真实声纹、录音、对话、习惯数据。
4. **儿童隐私优先**：测试输出不得包含真实儿童原话；回合账本只验证标签、身份、结果、时长、RMS 等元数据。
5. **一项失败就定位，不要继续掩盖**：记录命令、环境、预期、实际、日志和建议。

## 三、P0：核心大脑与人格

## 十九、OpenClaw 执行入口

优先：

```bash
git fetch origin
git checkout main
git pull
cd ~/tangtang
./tests/run.sh 2>/dev/null || true
```

如果仓库已有 `tests/run.sh`，先执行它；再按本计划补充缺失测试。不要为了让测试“通过”而修改测试预期。

实机测试前执行：

```bash
./code/cat/cat.sh hwcheck
./code/cat/cat.sh features
./code/cat/cat.sh presence
```

然后逐项执行 P0/P1。

**测试的目的不是证明糖糖已经完美，而是找到下一轮最值得修的问题。**
