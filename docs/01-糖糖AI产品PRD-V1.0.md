# 糖糖 AI｜产品 PRD V1.0

> 家庭投影陪伴智能体｜第一版产品需求文档

## 1. 产品概述

**产品名称：** 糖糖 AI（TangTang AI）  
**产品形态：** Mac Air 本地运行 + 家庭投影显示  
**当前阶段：** 投影陪伴原型

### 1.1 产品愿景

糖糖不是传统提醒工具，也不是聊天机器人，而是一只“住在家里的小狗”。它通过投影、动画和声音，以低打扰的方式陪伴家庭成员，帮助家庭形成更好的生活节奏。

**一句话定位：** 让一只可爱的小狗住进家里的投影里，陪伴家人生活。

## 2. 核心价值

- **高频陪伴入口：** 平时安静存在，需要时自然出现。
- **生活节奏管理：** 未来提醒睡觉、起床、散步、久坐和长时间看屏幕。
- **天气提醒：** 根据时间、天气和出行场景提供温和提示。
- **轻量互动：** 可以和糖糖说话、回应糖糖，但不追求持续聊天。
- **家庭陪伴：** 后续根据不同家庭成员角色和习惯提供差异化陪伴。

## 3. V1 产品范围

第一阶段不追求完整智能体，只建立“糖糖投影动画系统”。

### 必须实现

1. 糖糖角色加载与统一视觉
2. 待机生命感动画
3. 开心、好奇、困倦、睡觉、起床、欢迎、陪伴等状态
4. 尽可能真实的四肢行走动画
5. Animation Lab
6. 16:9 全屏 Projection Mode
7. 为未来 OpenClaw 控制预留本地状态接口

### V1 暂不实现

- 手机 App / Web 后台
- 用户系统与家庭账号
- 天气业务逻辑
- 作息提醒业务逻辑
- 复杂语音对话
- 智能家居控制
- HDMI 自动切换
- 数据统计和商业化

## 4. 硬件方案

当前方案：

```text
游戏机 ─────────→ 大眼橙 HDMI 1

MacBook Air
   ↓ USB-C → HDMI 转接器
   ↓
大眼橙 HDMI 2
```

Mac Air 负责运行糖糖程序，大眼橙负责投影显示。V1 不要求自动控制 HDMI 输入。

## 5. 核心架构

```text
OpenClaw / AI 决策层
        ↓
SugarStateMachine
        ↓
AnimationController
        ↓
Canvas / SVG Renderer
        ↓
Mac 全屏 Projection Mode
        ↓
大眼橙投影
```

**核心原则：** AI 决定“糖糖现在应该做什么”，动画系统决定“糖糖具体怎么动”。

## 6. 糖糖状态体系

| 状态 | 目的 |
|---|---|
| IDLE | 安静待机、保持生命感 |
| HAPPY | 开心、庆祝、积极回应 |
| CURIOUS | 好奇、认真观察用户 |
| SLEEPY | 困倦、准备休息 |
| SLEEPING | 安静睡觉、呼吸 |
| WAKE | 自然醒来、伸懒腰 |
| WELCOME | 欢迎家人回家 |
| CARING | 陪伴、提醒 |
| WALK | 散步、行走 |
| SIT | 坐下 |
| LIE | 趴下 |

## 7. 核心场景

### 7.1 晨间唤醒

糖糖从睡觉状态醒来，睁眼、抬头、起身、伸懒腰，以温和方式迎接一天。

### 7.2 长时间看屏幕

糖糖短暂出现，以动作 + 一句话提醒活动，不长时间打断游戏或视频。

示例：

> “看了好久啦，要不要陪我起来走两步？”

### 7.3 睡眠提醒

糖糖进入困倦状态，打哈欠、动作变慢，再趴下睡觉。

### 7.4 天气提醒

后续根据天气变化和出行计划提醒，例如：

> “今天有点凉哦，出门记得多穿一件。”

### 7.5 欢迎回家

抬头 → 耳朵竖起 → 站起 → 摇尾巴 → 向前走/跑两步 → 开心看向家人。

## 8. 交互原则

1. **少打扰：** 默认安静。
2. **先动作后语言：** 尽量用表情和动作表达。
3. **短出现：** 提醒完成后尽快退出。
4. **不说教：** 不使用居高临下的语气。
5. **保持连续人格：** 所有状态都是同一只糖糖。
6. **给选择：** 尽量使用“要不要”“陪我一起”等表达。

## 9. 动画需求

### IDLE

呼吸、眨眼、轻微歪头、耳朵和尾巴微动。

### HAPPY

身体轻微下沉后弹起、尾巴快速摇动、轻微跳跃，完成后恢复待机。

### CURIOUS

左右歪头、停顿、眨眼，表现认真观察。

### SLEEPY

眼睛变小、耳朵下降、打哈欠、低头、趴下。

### SLEEPING

以呼吸为核心，偶尔耳朵轻微抖动。

### WAKE

睁眼 → 抬头 → 前腿撑起 → 起身 → 伸懒腰 → 坐起 → 看向用户。

### WELCOME

抬头 → 站起 → 摇尾 → 向前走/跑两步 → 停下 → 开心看向用户。

### WALK

前腿、后腿、身体、尾巴尽可能独立运动。禁止只移动整张 PNG。

## 10. 技术要求

- 优先 HTML5 Canvas / SVG / CSS，也可使用 Electron + Canvas。
- macOS 稳定运行。
- 目标 60 FPS。
- 连续运行至少 8 小时。
- 不得出现持续内存增长或长期掉帧。
- 提供 Animation Lab。
- 提供 Projection Mode。
- 预留本地 HTTP API 或 WebSocket。

## 11. OpenClaw 接口预留

```http
POST /api/sugar/state
```

```json
{
  "state": "happy"
}
```

或：

```json
{
  "state": "caring",
  "message": "看了好久啦，起来活动一下吧"
}
```

## 12. 验收标准

- 糖糖看起来像“活着”，而不是一张图片在移动。
- 待机具有自然生命感。
- 主要情绪状态可切换且衔接自然。
- 起床、欢迎等动作有明确顺序。
- 散步不能只做整图平移。
- 投影全屏清爽，无开发 UI。
- Mac 长时间运行稳定。

## 13. 后续路线

- **V1.2：** 作息提醒、久坐/屏幕时间提醒
- **V1.3：** 天气提醒
- **V1.4：** 语音互动
- **V2：** 家庭成员角色、习惯记忆、个性化陪伴
- **V3：** App 与家庭硬件联动
