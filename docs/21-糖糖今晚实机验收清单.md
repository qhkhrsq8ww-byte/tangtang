# 糖糖今晚实机验收清单

版本基线：拉取当晚最新 `main`，先记录 commit SHA。只使用测试句子，不录制或提交真实儿童原话、声纹、录音。

## 0. 开始前

在仓库目录执行：

```bash
git fetch origin
git checkout main
git pull --ff-only
git rev-parse --short HEAD
git status --short
python3 tests/v4/run.py
```

如果自动化失败，先保存完整终端输出，不要继续用实机结果掩盖失败。确认 `TANGTANG_DATA_DIR` 指向临时测试目录；不要清理或覆盖现有家庭数据。

## 1. 基础链路与隐私

- [ ] 糖糖启动正常，无重复启动的服务或进程。
- [ ] 两位家庭成员分别主动呼叫，确认身份映射正确、回复风格符合年龄。
- [ ] 使用无敏感内容的测试句子检查：记录中只保留必要元数据；不得把儿童原话写入家庭共享摘要。
- [ ] 使用陌生访客测试：必须保持 unknown，不得默认绑定孩子，也不能读出家庭私密记忆。
- [ ] 断网或关闭 LLM 网关后再主动呼叫：应给出短回退，不应卡死或返回空白。
- [ ] TTS 暂不可用时：确认日志能看出播放失败，事件记录仍保留；检查是否出现重复播报。

## 2. 记忆闭环

只用虚构测试偏好，例如“请记住我喜欢青苹果”。

- [ ] 明确提出记住后，糖糖确认已记住；未明确要求时不应擅自长期保存偏好。
- [ ] 同一成员询问“你还记得我喜欢什么吗”，能回忆刚才的偏好。
- [ ] 另一个家庭成员询问时，不得读出前一个人的 PRIVATE 记忆。
- [ ] 明确要求忘记后再次询问，不应继续回忆该条偏好。
- [ ] 重启后再次检查：有效偏好可按设计恢复；已忘记内容不应重新出现。
- [ ] 测试结束后清除本轮临时测试数据，不要删除真实家庭数据目录。

## 3. 主动陪伴与打扰边界

- [ ] 正常白天回家场景最多主动问候一次。
- [ ] 同一成员短时间内重复触发同类场景，不连续播报。
- [ ] 22:00 至 07:00 主动场景保持静默。
- [ ] 模拟上学、睡眠状态，主动场景不打扰。
- [ ] 用户主动呼叫时，即使在安静时段也进入正常对话流程。
- [ ] 用户明确说“不想说话/别打扰我”后，观察旧版主动提醒是否仍继续触发；若触发，记录复现步骤，暂不把此项标记为通过。

## 4. 故障恢复与持续运行

- [ ] 拔掉/断开音箱后触发一次对话，程序不崩溃；恢复音箱后可以继续工作。
- [ ] 临时关闭网络，确认本地回退可用；恢复网络后不需要手工清空状态。
- [ ] 连续运行 30 分钟，观察 CPU、内存、进程数量、临时音频文件和重复播报。
- [ ] 重启糖糖后，确认记忆可读取、任务状态合理，没有重复提醒或跨成员记忆。
- [ ] 数据目录只读或暂时不可写时，记录功能应明确报错/降级，不应把敏感内容转写到其他位置。

## 结果回传

请记录：设备与 macOS 版本、仓库 commit、自动化测试结果、每项 PASS/FAIL/SKIP、失败的复现步骤和错误日志。不要附上真实儿童原话、录音、声纹、密钥或完整私密记忆文件。

**判定规则：**云端自动化通过只代表软件测试通过；麦克风、蓝牙音箱、投影和实际语音自然度只能由客厅实机验证。
