# 糖糖打扰决策引擎 V1.0

## 核心原则

**聪明不是更会说，而是更知道什么时候不说。**

糖糖每次主动提醒前，都经过 `ShouldInterrupt` 判断。默认允许静默。

## 输入

- 成员身份与置信度
- 当前时间
- 当前成员最近互动时间
- 当前场景（学习/游戏/吃饭/睡觉/家庭聊天等）
- 今日已经提醒次数
- 最近同类提醒是否被拒绝
- 行为趋势是否真的发生变化
- 提醒优先级

## 输出

```json
{
  "decision": "speak",
  "priority": "normal",
  "reason": "screen_long",
  "cooldown_minutes": 30,
  "action": "caring"
}
```

`decision`：`silent | speak | emergency`

## 规则

### 默认静默

以下情况优先静默：

- 没有明确事件
- 刚刚已经提醒过同一件事
- 成员连续拒绝同类提醒
- 当前处于电影/游戏/家庭聊天等高打扰场景
- 声音识别置信度不足

### 普通提醒

例如屏幕使用时间较长：

1. 第一次：轻提醒
2. 被拒绝：进入冷却
3. 冷却结束后仍持续：再次轻提醒
4. 多次拒绝：停止说教，改为动作示范

### 趋势提醒

只有当趋势达到最低样本数时才触发，例如：

- 至少 3 个有效观察日
- 或连续出现明显变化

不得因为一次晚睡、一次没运动就给出“最近习惯不好”的结论。

## 年龄策略

### 9岁 PLAY

优先使用挑战、陪伴、动作示范：

“来，糖糖挑战你！”

### 12岁 FRIEND

优先使用尊重和选择：

“糖糖提醒一下，你自己决定就好。”

### 成人/长辈

自然、简短，不幼态化。

## 安全优先

涉及明显危险、严重身体不适、自伤/伤害他人等高风险表达时，不使用普通提醒冷却规则，应转入安全流程，并鼓励联系可信任成年人或专业人员。
