# 糖糖家庭网络设备管控方案（基于 2026-10-20 设备扫描）

> 状态：设计方案，尚未授权真实设备自动断网。  
> 依据：`docs/network-scan-20261020.md`；路由器为小米 R3D，管理地址 `192.168.31.1`。  
> 原则：先识别、再授权、后控制；默认只读；未确认归属的设备不自动封禁；任何故障均不得影响糖糖宿主机和路由器管理通道。

- 扫描结果中的“4 台手机”并不代表这 4 台都属于儿童；必须由家长逐台确认。

## 2. 功能范围

### V1：只读探测与设备登记
1. 读取路由器设备列表，归一化名称、MAC、IP、在线状态、连接类型和路由器返回的联网权限。
2. 对设备记录生成稳定内部 ID（优先基于标准化 MAC），IP 仅作为最近观察值。
3. 输出 JSON 和人类可读摘要；标明采集时间、数据来源和失败项。
4. 对路由器 API 不可用、登录失败、返回结构变化、扫描超时等情况明确报错；禁止把失败误判为“设备离线”。
5. 不主动扫描公网；只探测明确配置的家庭 LAN 网段。端口探测默认关闭，需要时只对家庭设备执行，并记录用途。

### V2：经家长确认的单设备断网/恢复
1. 仅允许对已登记且已由家长确认归属的设备执行。
2. 每次控制都要求独立授权、目标 MAC 精确确认、操作前展示设备名/MAC/当前状态。
3. 保护路由器、糖糖宿主 Mac、管理终端，以及家长明确标记的关键设备。
4. 控制后重新读取路由器状态进行核验；若结果不确定，报告“状态未知”，不重复盲目重试。
5. 恢复联网必须可单独执行；提供人工紧急恢复流程。

### V3：定时规则
1. 仅对已确认的儿童设备启用；默认不配置任何真实设备规则。
2. 规则按本地时区执行，支持工作日、周末、例外日期、临时延长和立即恢复。
3. 定时任务必须幂等；重复运行不应造成状态反复切换。
4. Mac 离线、路由器离线、认证失败或配置损坏时，不扩大断网范围；记录故障并通知家长。
5. 每条规则均有启用开关、创建/修改时间、目标设备、断网窗口、最后执行结果和恢复结果。

### V4：语音入口
1. 儿童可查询“哪些已登记设备在线”“我的设备何时恢复联网”等非敏感状态。
2. 语音可以发起控制请求，但**儿童说出指令、LLM 判断或识别到某个名字均不等于家长授权**。
3. 断网、恢复、规则变更必须走独立家长确认通道；确认凭据不能由模型生成，也不能仅靠提示词约束。
4. 不在语音日志、公开仓库或模型上下文中保存路由器密码、stok、完整家庭设备标识等秘密。

## 3. 设备分组与规则建议

| 分组 | 纳入条件 | 推荐策略 | 默认状态 |
|---|---|---|---|
| 儿童个人设备 | 家长明确确认设备归属及 MAC | 可配置睡眠时段、作业时段；允许临时延期 | 关闭，等待确认 |
| 家长个人设备 | 家长确认 | 不做自动断网 | 永不自动管控 |
| 糖糖宿主/管理设备 | 与服务运行及恢复控制有关 | 永不自动断网，加入硬性保护名单 | 强制保护 |
| 路由器/网关 | 固定网关身份 | 禁止作为控制目标 | 强制保护 |
| 打印机及其他 IoT | 家长确认用途 | 默认常通；需要时另行制定规则 | 不自动管控 |
| 未知设备 | 尚未完成指认 | 只读记录、提醒家长核对 | 不自动封禁 |

**时段建议只作为待确认的模板，不直接启用：**
- 夜间窗口候选：22:30–07:00。
- 作业时段候选：由家长另行设置，不预设固定时段。
- 周末策略：单独配置，不自动沿用工作日规则。
- 临时延期：允许家长选择延长 15/30/60 分钟，到期回归原规则；不能因为临时延期失败而永久封禁设备。

## 4. 技术结构与文件边界

- `code/cat/cat-router.py`：现有路由器管理 CLI。只读命令与修改命令必须分离；任何修改命令都应经过统一安全校验。
- `core/integrations/miwifi_router.py`：路由器 API 适配器候选，负责只读设备清单和受控联网权限变更；需在真实 R3D 固件上再次验证。
- 建议新增 `code/cat/cat-scan.py`：只读探测、设备归一化和 JSON 输出。不要把扫描逻辑混进语音主链路。
- 建议新增 `code/cat/cat-router-schedule.sh` 或独立 Python 调度器：专门处理网络规则。
- `code/cat/cat-schedule.sh` 已有糖糖提醒/日程用途，**不得复用、覆盖或改名来承担路由器断网调度**。
- 建议新增本机配置文件 `code/cat/router-devices.local.json` 和 `router-schedule.local.json`；仅提交不含真实 MAC 的模板文件。真实配置应加入 git 忽略规则。
- 不应把完整扫描报告、真实 MAC、家庭设备映射、路由器密钥或会话 token 放入公开仓库。公开报告保留必要的脱敏示例即可。

## 5. 安全校验要求（必须满足后才能启用写操作）

1. **默认只读**：未显式设置本地开关时，任何写操作都拒绝执行。
2. **目标白名单**：只能控制本地配置中由家长确认的设备；不能只因为输入了 MAC 就允许操作。
3. **保护名单**：路由器 MAC、糖糖宿主机 MAC、家长管理终端 MAC 和人工标记的关键设备始终拒绝控制。保护规则在调度配置中也不可覆盖。
4. **精确确认**：执行前要求对目标 MAC 做完整确认；不能只用设备名、IP 尾号或语音识别文本。
5. **权限分离**：儿童对话、普通 LLM 意图解析与家长授权分离。模型不能设置授权变量、修改白名单或自行更改安全配置。
6. **最小权限**：只允许调用固定的设备清单和联网权限接口；禁止从用户输入拼接任意 URL、路径或命令。
7. **安全失败**：认证失败、未知设备、配置解析失败、状态不确定时拒绝写操作；不得自动扩大目标集合。
8. **可审计**：记录时间、操作者/授权来源、设备内部 ID、动作、结果和错误类型；日志默认不输出凭据与完整敏感标识。
9. **恢复能力**：每个断网操作有对应恢复路径；提供只针对指定设备的手动恢复命令和操作说明。
10. **速率限制**：控制操作串行执行并设置超时；失败后不进行无限重试。
11. **防止配置误操作**：上线前校验目标设备不在保护名单；规则配置修改须先做 dry-run 并输出计划变更。
12. **凭据保护**：`.router_key` 仅保存在本机并限制文件权限；代码不得在错误信息中输出密码、token、登录响应敏感字段。

## 6. 规则执行流程

1. 读取本地配置并校验 schema、时区、目标设备和保护名单。
2. 获取最新路由器设备清单；若无法确认路由器状态，终止本轮控制。
3. 对每个目标设备计算“应该联网/应该断网”状态，并输出 dry-run 计划。
4. 检查目标是否已获家长授权、是否在保护名单、是否处于例外时段。
5. 执行单个设备的变更；不对未授权或未知设备采取动作。
6. 重新读取路由器设备清单，核验联网权限是否改变。
7. 写入脱敏审计日志；把失败、跳过和状态未知分别记录。
8. 调度器下一轮只重试可安全重试的读取操作；写操作必须重新核验状态与授权。

## 7. 测试验收清单

### 自动化测试（不需要真实路由器）
- MAC 大小写、分隔符和非法格式归一化。
- 未开启写操作开关时，block/unblock 全部拒绝。
- 未确认设备、未知设备、目标 MAC 不匹配时拒绝。
- 路由器、宿主 Mac、家长设备及关键设备保护名单无法被绕过。
- 配置文件缺失、格式错误、时区错误、重复设备 ID 时 fail-closed。
- 断网窗口跨午夜、工作日/周末、例外日期、临时延期的边界测试。
- 路由器 API 超时、登录失效、响应结构变化、返回非零 code 时不误报成功。
- 控制后状态核验失败时记录“状态未知”，不盲目重复写操作。
- 调度任务重复执行幂等；并发执行有锁；日志不包含凭据。
- 儿童语音请求不能直接调用写接口，家长授权缺失时只提供请求说明。

### 家庭局域网验收（需人工执行）
1. 先仅运行只读设备清单和扫描，人工核对所有设备。
2. 对 Unknown 设备进行家庭核对，不自动封禁。
3. 选择一台非关键、已获家长确认的测试设备，手动测试断网和恢复。
4. 断网后确认糖糖宿主、路由器管理入口和家长设备仍可用。
5. 在测试设备上验证规则生效和恢复；随后验证路由器断电/网络中断后的恢复流程。
6. 验收通过前，不注册定时任务、不接入儿童语音写操作。
