## 三、实现架构（阶段化）

**阶段 1（本周）—— cat-schedule 定时管控**
- 新增 code/cat/cat-schedule.sh：读 schedule.json（设备 MAC + 时段表）→ 当前时间落在断网窗 → block，出窗 → unblock
- schedule.json 模板入仓库（真实 MAC 存本机）
- LaunchAgent 每 5 分钟跑一次（幂等，重复执行无害）
- 决策点需家长填写：孩子手机 MAC、断网窗口（默认 22:30–07:00）、周末是否豁免

**阶段 2（下周）—— 糖糖语音/文案联动**
- 22:30 断网同时糖糖说"该睡觉啦"；07:00 恢复时糖糖说早安
- 语音指令扩展：断网/恢复/查设备

**阶段 3（可选）—— 高级**
- 米家云通道（小米账号授权）：限速/更细控制
- Unknown 设备指认与准入管理

## 四、安全边界（继承 ADR-0006）

1. 管控脚本只操作 MAC 黑名单，不改路由器其他配置（DHCP/WiFi 密码等禁动）
2. 家长设备与管理机永不在断网名单（硬编码保护，schedule.json 也不允许加入）
3. 路由器密码 .router_key 600 不入库（已执行）
4. 公开仓库报告中 MAC/IP 脱敏（已执行）
