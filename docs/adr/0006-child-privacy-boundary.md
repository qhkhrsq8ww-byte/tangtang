# ADR-0006: 儿童隐私边界

## Status: Accepted；含 P0 整改（2026-10-19）

## Context
糖糖面向儿童运行。既有设计原则（散落在各脚本注释中，本次收敛为正式 ADR）：儿童原话不落盘、声纹与习惯流水只存本机、密钥不入库、STT 结果只用于本机关键词、不追问不训斥不加大音量。

## Decision
五条边界为长期架构约束，任何新模块（含 V2）必须继承：①儿童语音 PCM 即用即删；②原话与声纹不入库不外传；③密钥（.llm_key/.baidu_token/cat-stt-config.sh）只存本机且 gitignore；④家庭结构与上学日历不入库（2026-10-19 起执行，此前被追踪的四个文件已解除追踪）；⑤公开渠道（含仓库、日志、报告）一律使用化名（姐姐/弟弟）。

## Consequences
正：隐私约束进入评审基线，新代码可对照检查。
负：历史提交仍含数据文件与昵称，需要 filter-repo 清理（待办）；报告类文档需人工注意化名纪律（本次审核报告已执行）。
