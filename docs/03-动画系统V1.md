# 糖糖 AI｜动画系统 V1

## 1. 阶段目标

第一阶段只解决：让糖糖在 Mac 上真正“活起来”。

暂不开发 App、天气、作息、家庭成员、智能家居、HDMI 自动切换和复杂 Agent。

## 2. 角色要求

使用现有糖糖比熊形象作为唯一视觉基础。保持白色蓬松比熊、圆脸、黑色大眼睛、棕色鼻子、黄色项圈和糖糖铭牌。

禁止重新设计角色、改变品种、换画风或让不同状态看起来像不同的狗。

## 3. 技术架构

```text
SugarCharacter
      ↓
SugarStateMachine
      ↓
AnimationController
      ↓
Canvas / SVG Renderer
      ↓
Mac 全屏 Projection Mode
```

优先使用 HTML5 Canvas / SVG / CSS；也可以使用 Electron + Canvas。以 macOS 稳定运行、低资源占用为优先。

## 4. 状态

- IDLE：待机
- HAPPY：开心
- CURIOUS：好奇
- SLEEPY：困倦
- SLEEPING：睡觉
- WAKE：起床
- WELCOME：欢迎
- CARING：陪伴/提醒
- WALK：散步/行走
- SIT：坐下
- LIE：趴下

## 5. IDLE 基础生命感

身体缓慢呼吸、随机眨眼、头部轻微变化、耳朵极小幅度运动、尾巴偶尔轻摆。动作幅度必须自然，不能像机械弹簧。

## 6. 关键动画

### HAPPY
身体轻微下沉后弹起，尾巴快速摇摆，头部轻微向上，可小幅跳跃 2～3 次后回到待机。

### CURIOUS
头向左倾斜 → 停顿 → 恢复 → 向右倾斜 → 眨眼，表现“正在认真看你”。

### SLEEPY
眼睛变小、耳朵下降、头部向下、打哈欠、身体放松，然后趴下。

### SLEEPING
趴在小窝里，以呼吸作为核心动作；偶尔耳朵轻微抖动。

### WAKE
趴着 → 睁眼 → 抬头 → 前腿撑起 → 起身 → 伸懒腰 → 坐起 → 看向用户 → 尾巴轻摇。

### WELCOME
趴着 → 抬头 → 耳朵竖起 → 看向用户 → 站起 → 尾巴快速摇 → 向前走/跑两步 → 停下 → 开心看向用户。

### CARING
采用坐姿或站姿，轻微歪头、眨眼、尾巴慢摆。后续可叠加提醒文字。

### WALK
不能用整张 PNG 横向移动冒充走路。尽可能让前腿、后腿、身体和尾巴独立运动。优先建立分层素材和简单 2D 骨骼/局部变形系统。

## 7. 素材目录建议

```text
assets/sugar/
├── base/
├── states/
├── parts/
└── animations/
```

parts 至少考虑：head、body、front_leg_l、front_leg_r、back_leg_l、back_leg_r、tail、ear_l、ear_r。

如果当前 PNG 无法立即分层，先完成 LEVEL 1 的生命感动画，再进入 LEVEL 2 的身体分层动画。

## 8. 状态调用接口

```js
sugar.setState("idle")
sugar.setState("happy")
sugar.setState("curious")
sugar.setState("sleepy")
sugar.setState("sleeping")
sugar.setState("wake")
sugar.setState("welcome")
sugar.setState("caring")
sugar.setState("walk")
```

支持 `onAnimationComplete()`，使 WELCOME → HAPPY → IDLE、WAKE → IDLE、SLEEPY → SLEEPING 等状态可以自然衔接。

## 9. Animation Lab

提供开发测试页，可点击各状态按钮直接观察动画。显示当前 State、Current Animation、FPS。该页面仅供开发测试，不是最终产品 UI。

## 10. Projection Mode

16:9 全屏、隐藏按钮和开发信息。糖糖是唯一视觉主体。最终体验应该像“糖糖住在投影里”，而不是一个 Dashboard。

## 11. 性能

目标 60 FPS；CPU 占用尽可能低；连续运行至少 8 小时；不得出现持续内存增长或运行越久越卡的问题。

## 12. 验收原则

核心标准不是代码量，而是“糖糖是否真的像活着”。

否决项：仅整体平移、缩放、旋转 PNG，不能视为真正的角色动画。

## 13. 后续 OpenClaw 接口预留

未来可提供：

```text
POST /api/sugar/state
{
  "state": "happy"
}
```

或者：

```text
{
  "state": "caring",
  "message": "看了好久啦，起来活动一下吧"
}
```

OpenClaw 负责决定“糖糖现在应该做什么”，动画引擎负责“糖糖具体怎么动”。
