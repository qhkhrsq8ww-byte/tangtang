# 蚂蚁灵光 vs 糖糖：定位对比与接入可行性（2026-10-29）

## 结论

灵光（蚂蚁集团 2025-11-18 发布的全模态 AI 助手 App）与糖糖不是同一物种：灵光是**云端消费级通用助手 App**，糖糖是**自建的家庭嵌入式陪伴系统**。目前灵光**没有公开 API**，无法被糖糖直接调用；推荐做法是把灵光 App 装在孩子手机上当"随身 AI"，与客厅的糖糖形成互补，不打通。

## 定位对比

| 维度 | 蚂蚁灵光 | 糖糖 |
|---|---|---|
| 形态 | 手机 App（iOS/Android，云端托管） | 自建系统（Mac + 投影 + 音箱，全本机） |
| 核心能力 | 全模态对话、30 秒生成"闪应用"、灵光开眼（视觉） | 规则大脑+云端大脑、晨间唤醒、定时管控、设备联动 |
| 部署与数据 | 蚂蚁云端 | 全本机（隐私自控，儿童原话不落盘） |
| 定制性 | 标准化产品，不可编程 | 人设/话术/行为/管控全可编程 |
| 开放性 | 无公开 API（闪应用仅 App 内运行） | OpenAI 兼容云脑端点，可随时换模型 |

## 接入可行性

1. 直接接入（调用灵光 API）：❌ 目前无公开 API
2. 互补共存（推荐）：孩子手机装灵光 App（随身 AI），客厅糖糖（家庭宠物），互不打扰
3. 未来观察：若灵光开放智能体/模型 API，再评估接入糖糖云脑
