# 糖糖生活伙伴 V1：日常任务与提醒

状态：代码已提交，等待当前 main 的 CI 最终结果；尚未部署到家庭 Mac。

## 能力

- 语音中明确说“提醒我……”时，走本地任务服务，不把整句原话写入任务存储。
- 支持“我的任务”“我做完了任务名称”“取消任务任务名称”。
- 支持明确日期和时间，例如“提醒我明天晚上八点做作业”“提醒我后天 19:30 带水杯”。
- 没有明确时间时只保存为待定任务，并询问何时提醒，不猜时间。
- 默认 PRIVATE；只有明确说“全家一起 / 大家一起 / 我们家一起 / 全家都 / 大家都 / 家庭共享”才创建 FAMILY 任务。
- 到期派发器只通过客厅音箱播报 FAMILY 任务。PRIVATE 任务不会把标题说出来；到期时转为 needs_confirmation，并尝试发出不含任务详情的 macOS 通知。
- 安静时段默认 22:30–07:00。普通家庭任务在安静时段到期会转为待确认，不在第二天早晨突然补播。
- 重复说同一任务和同一提醒时间会使用幂等键，避免重复创建。

## 语音示例

- “糖糖，提醒我明天晚上八点做作业。”
- “糖糖，我的任务。”
- “糖糖，我做完了做作业。”
- “糖糖，取消任务整理书包。”
- “糖糖，提醒我们家一起明天晚上七点半整理客厅。”（家庭共享）

## Mac 命令

在已部署的运行目录中：终端命令需提供真实的成员 ID（示例使用 hanghang）；语音入口会根据当前已识别的家庭成员自动确定 owner。

```bash
./cat.sh task --owner hanghang list
./cat.sh task --owner hanghang add "带水杯" --due 2026-10-21T08:00:00+08:00
./cat.sh task --owner hanghang add "整理书包"
./cat.sh task --owner hanghang done <task_id>
./cat.sh task --owner hanghang cancel <task_id>
```

添加命令的 `--due` 必须是带时区偏移的 ISO 8601，例如 `2026-10-21T08:00:00+08:00`。个人任务默认不公开播报。需要共享的任务必须显式使用 `--visibility FAMILY`。

要启用定时派发，先运行 `./cat-schedule.sh crontab` 预览生成内容，检查路径和本机环境后，再手动合并到 crontab；不要直接覆盖原有 crontab。生成的任务派发条目每分钟检查一次，派发器使用文件锁避免重入。

## 边界与待验收项

- CI 通过仅说明自动化测试通过，不代表本机语音识别、TTS、macOS 通知或 cron 已经实际运行。
- 本地任务数据放在 TangTang 数据目录的 `tasks/tasks.json`，不放进 Git。
- PRIVATE 任务目前不会在公共音箱播报；要真正送达个人设备，后续需接入用户明确授权的私有通知通道。
- 时间解析只支持明确、常见的日期和时刻格式。含糊的“晚点”“一会儿”不会被自动猜成具体时间。
