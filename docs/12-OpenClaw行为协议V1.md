# 糖糖AI｜OpenClaw行为协议 V1

## 目标

OpenClaw负责“判断糖糖现在是否应该做什么”，表现层负责“怎么表现”。

## 标准事件

```json
{
  "type": "TANGTANG_ACTION",
  "profile": "play",
  "action": "caring",
  "message": "看了好久啦，要不要起来走两步？",
  "priority": "normal",
  "loop": false
}
```

## 决策顺序

1. 是否真的需要打扰？
2. 当前家庭成员是谁？
3. 选择年龄人格：9岁=play，12岁=friend。
4. 是否刚提醒过同一主题？
5. 选择最轻量的提醒方式。
6. 决定动作、语音和文案。
7. 完成后记录“是否响应”，而不是只记录“是否提醒”。

## 打扰等级

- `silent`：只记录，不展示。
- `low`：动作，不说话。
- `normal`：动作 + 一句话。
- `important`：动作 + 语音；涉及安全时升级成年人。

## 自我优化

OpenClaw可以分析匿名的行为结果并提出优化建议，但不得自动修改核心代码或安全策略。

```text
观察 → 分析 → 提案 → 测试 → 人工确认 → 发布
```

## 失败保护

AI服务不可用时，糖糖仍能运行本地动画；TTS失败时不影响投影；数据文件损坏时不得删除原始备份。
