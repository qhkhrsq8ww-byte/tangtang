## 六、Mac 合盖运行（用户需求）

### 当前状态
- Mac 合盖会强制睡眠（硬件级）
- 用户希望"合盖也能运行，只有关机才停止"

### 方案
方案 B（用户已选）：**Mini DisplayPort → HDMI 转接头**触发 clamshell 模式
- 2013 MacBook Air 只有 Mini DP 口（雷电1，小梯形）
- 需买 Mini DP（公）→ HDMI（母）**无源转接头**（绿联/山泽，约 20-50 元）
- 插上后合盖，外接投影仪当显示器，糖糖继续运行

### 需求
- [ ] 用户购买 Mini DP → HDMI 转接头
- [ ] 确认投影仪 HDMI 输入切换
- [ ] 验证合盖后糖糖继续工作

## 七、Mac 永不休眠（待用户执行）

### 需求
用户自行在 Mac 终端运行（需要 sudo 密码）：
```bash
# 永久禁止休眠（需密码）
sudo pmset -a sleep 0 disksleep 0 autopoweroff 0 standby 0

# 恢复默认（如需）
sudo pmset -a sleep 1 autopoweroff 1 standby 1
```
