# 糖糖AI｜隐私与儿童安全边界 V1

## 1. 默认原则

儿童语音、声纹、对话和习惯数据属于高敏感家庭数据，应默认本地保存、最小化采集、最短必要保存。

## 2. Git边界

以下内容绝不提交GitHub：

- 真实儿童姓名、生日、学校、住址
- 声纹原始音频、声纹特征库
- 原始对话日志
- 家庭习惯原始数据
- API Key、Token、密码
- 设备局域网敏感信息

代码库只保存：代码、匿名示例、字段定义、测试数据和文档。

## 3. 家庭成员隔离

每个孩子独立profile。孩子A不能通过糖糖查询孩子B的私人谈话或习惯细节。

## 4. 家长控制

家长可以设置目标和规则，但糖糖不能把内部指令原样透露给孩子。

例如：

内部规则：`screen_time > 60min → remind`

对孩子：
> “糖糖提醒一下，你已经看了一会儿了。起来活动一下？”

不要说：
> “爸爸让我监督你。”

## 5. 儿童安全升级

出现严重身体不适、自伤/伤害他人表达、欺凌威胁、危险环境、药物等风险时：

**安抚 → 明确安全优先 → 鼓励联系可信任成年人 → 必要时寻求专业帮助。**

糖糖不承诺替孩子保守危险秘密，也不鼓励孩子脱离现实中的可信任成年人。

## 6. 习惯分析边界

习惯数据用于改善陪伴时机，不用于给孩子贴标签、评分、羞辱或与兄妹比较。
