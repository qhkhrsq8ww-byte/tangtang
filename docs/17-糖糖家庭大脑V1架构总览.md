# 糖糖家庭大脑 V1.0

> 目标：把糖糖从“语音聊天 + 投影形象”升级为能够认识家庭、理解成员、记录行为、形成趋势并谨慎主动陪伴的家庭 AI。

## 一、核心原则

1. **身份与行为分离**：声纹只回答“是谁”，行为系统回答“发生了什么”。
2. **事件优先**：所有可观察行为统一转成事件，不直接修改长期人格。
3. **记忆分层**：今日记忆、近期趋势、长期习惯、重要记忆分开存储。
4. **先判断再说话**：任何主动提醒先经过打扰决策引擎。
5. **AI 与表现层解耦**：AI决定意图、文案和动作ID；播放器负责视频/图片/声音。
6. **本地优先**：声纹、原始语音、儿童私人对话、家庭敏感数据默认留在本机。
7. **不因一次事件下结论**：长期趋势必须达到最低样本量。
8. **儿童隐私优先**：儿童私人对话默认不进入家庭共享摘要。

## 四、多人家庭模型

每个成员使用稳定 `member_id`，不要用姓名作为主键。建议支持：爷爷、奶奶、爸爸、妈妈、12岁女孩、9岁男孩，并允许以后继续增加成员。

每个成员至少拥有：

- 身份与关系
- 年龄/年龄段
- 人格 Profile
- 声纹引用与置信度
- 权限
- 提醒偏好
- 个人偏好
- 今日行为
- 近期趋势
- 长期习惯
- 重要记忆

## 五、行为事件

所有行为统一事件模型：

```json
{
  "event_id": "evt_xxx",
  "member_id": "member_xxx",
  "timestamp": "2026-08-28T12:00:00+08:00",
  "type": "screen",
  "value": {"minutes": 45},
  "source": "voice",
  "confidence": 0.92,
  "privacy": "private"
}
```

事件类型至少包括：`wake`、`sleep`、`meal`、`water`、`exercise`、`screen`、`study`、`work`、`outdoor`、`home`、`chore`、`conversation`、`mood_signal`、`interaction`。

## 六、记忆生命周期

```text
原始事件
  ↓
今日记忆 L1
  ↓（聚合）
7~30日趋势 L2
  ↓（达到样本阈值）
稳定习惯 L3
```

重要记忆单独管理，不由模型自行永久保存。

## 七、家庭上下文

每次需要回答或主动提醒时，构造最小必要上下文：

```json
{
  "member": {"id":"child_9","age":9,"profile":"play"},
  "time": "21:15",
  "scene": "home",
  "today": {"screen_minutes": 92,"exercise_minutes": 8,"homework_done": false},
  "recent": {"screen_7d_avg": 82},
  "last_interaction": "20:40",
  "policy": {"privacy":"child_private","interrupt":"normal"}
}
```

不要把整个家庭数据库直接塞给模型。

## 八、AI输出协议

AI/规则层只输出结构化意图，不直接操作文件：

```json
{
  "type": "TANGTANG_RESPONSE",
  "decision": "speak",
  "member_id": "child_9",
  "profile": "play",
  "message": "来，糖糖陪你起来走两分钟！",
  "action": "caring",
  "priority": "normal"
}
```

## 九、表现层

`action` 由媒体注册表映射到实际资源，例如：

```text
caring → assets/videos/caring.webm
walk   → assets/videos/walk.webm
happy  → assets/videos/happy.webm
```

AI不能写入绝对路径，也不能直接执行 shell 命令。

## 十、安全边界

- `unknown` 不自动绑定家庭成员。
- 声纹置信度不足时进入 unknown/澄清流程。
- 儿童私人对话默认 private。
- 高风险安全事件不受普通提醒冷却限制。
- 任何长期结论必须有可追溯事件来源。
- 运行时敏感数据禁止提交 Git。
- OpenClaw 可以提出优化建议，但不得自行修改安全策略并上线。

## 十一、V1落地顺序

1. 建立 `family/` 成员注册与权限层。
2. 建立 `memory/` 事件日志与今日记忆。
3. 建立 `context/` 最小上下文构建器。
4. 将现有声纹识别接入 Identity Resolver。
5. 将 `ShouldInterrupt` 接入所有主动提醒。
6. 将 AI 输出统一为 `TANGTANG_RESPONSE`。
7. 建立媒体注册表，接入 PNG/视频两种表现形式。
8. 最后再做 7~30 日趋势和长期习惯学习。
