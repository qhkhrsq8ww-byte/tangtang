## 四、给团队的修复/改进清单

1. edge-tts 依赖需固定 ≥7.3.1（微软端校验收紧，旧版 403）——建议入 requirements
2. proactive/reminder 脚本日志加时间戳（当前 err.log 无时间戳，排障困难）

4. 话术表与儿童安全词表交叉审查（"想死"类日常用语 vs RISK_MARKERS）
