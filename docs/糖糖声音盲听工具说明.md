# 糖糖声音盲听工具

## 用途

自动生成同一句中文试听文本的多种普通话女声音色，并将文件随机标记为 A、B、C……，尽量避免默认音色总是排在第一个。试听前先填评分表，最后再看答案。此工具只生成本地试听文件，不会更改生产默认音色，也不会上传评分或孩子的语音。

## 运行

先同步主分支变更，再在糖糖仓库根目录运行：

```bash
/usr/bin/python3 code/cat/cat-voice-lab.py
```

如需生成后自动在 Mac 上依次播放：

```bash
/usr/bin/python3 code/cat/cat-voice-lab.py --play
```

样本默认保存到桌面上的 `TangTangVoiceLab-日期时间` 文件夹；若没有桌面目录，则保存到用户主目录。程序会从 Edge TTS 当前可用音色中选择最多 6 种普通话女声，生成 `盲听样本/A.mp3`、`B.mp3` 等文件，并创建评分表和单独的答案文件。所有候选使用相同文本、语速 -5%、原始音高。若想增加或更换试听文本，可添加 `--text "你的试听文本"`。

> 首次运行需要能访问 Edge TTS 服务；当前 Python 环境需要已安装 `edge-tts`。生产默认音色仍是 `zh-CN-XiaoxiaoNeural`。

## 评分标准

每个样本按 1–5 分评估自然程度、温柔亲切、糖糖匹配度、长时间听是否疲劳。选“自然、像家里伙伴、耐听”的音色，不以“最萌”为唯一标准。确定候选后，再决定是否通过本机环境变量 `TANGTANG_TTS_VOICE` 切换；不要为了试听直接改写生产默认值。
