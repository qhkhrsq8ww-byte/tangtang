# 糖糖 V3 家庭大脑本轮落地说明

本分支只做已经由 V3 实测报告证明必要的 P0/P1 修复，不把实验性休息日大分支整体并入 main。

## 已落地

1. `data/family.json`：正式五口之家：爷爷、奶奶、爸爸、洽洽（~12，friend）、航航（~9，play）。姐姐→qiaqia、弟弟→hanghang 只作别名。妈妈不是正式成员。
2. `tangtang-profile.py`：把声纹识别得到的 member_id/称呼解析为关系与 persona。
3. `cat-chat.py`：正式支持 `play / friend / adult / elder` 四类人格，并从家庭成员库解析身份。
4. `cat-voice.sh`：先客厅在场（WiFi/ARP + 短窗能量），声纹只作可选兜底，再进入对话人格。
5. `tangtang-quiet-hours.py`：统一夜间静默闸门，默认 22:30–07:00；静默只禁止主动发声，不删除事件。
6. `cat-talk.sh`：接入静默闸门；主动提醒夜间不出声。
7. `tests/test-v3-family.sh`：增加家庭角色、脚本语法、JSON、夜间边界回归测试。
8. `config/com.tangtang.daemon.plist.example`：为 Mac 的 launchd 迁移提供模板；实际安装时必须把 `__TANGTANG_HOME__` 替换为本机路径。

## 暂不处理

- 百度 STT 密钥不入库，使用本机 secret 环境变量。
- Wake Word 暂不作为 V3 P0。
- ffmpeg 二进制不提交 Git，使用本机依赖检查/安装流程。
- 旧 `cat-*` 记忆不直接删除，后续做事实迁移。
- 实验性 `rest-day-plan / habit-growth / openclaw-report` 分支不整体合并，避免把大量旧代码重新覆盖 main。
