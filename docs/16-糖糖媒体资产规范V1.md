# 糖糖媒体资产规范 V1.0

## 目标

糖糖的表现层采用“短视频动作优先、PNG/SVG辅助”的路线，方便投影播放和 OpenClaw 调度。

## 推荐目录

```text
assets/
├── character/
│   ├── idle/
│   ├── happy/
│   ├── caring/
│   ├── curious/
│   ├── thinking/
│   ├── sleepy/
│   ├── sleeping/
│   ├── wakeup/
│   └── welcome/
├── animation/
│   ├── walk/
│   ├── run/
│   ├── jump/
│   ├── paw/
│   └── stretch/
└── thumbnails/
```

## 视频规范

- 单动作 2～5 秒优先
- WebM 优先，必要时提供 MP4 fallback
- 尽量透明背景；如果编码链路不支持透明，则使用统一纯色/抠像背景
- 720p 起步，投影主素材建议 1080p
- 文件名使用稳定动作 ID，不使用中文和日期作为唯一标识

## 动作 ID

`idle`, `happy`, `caring`, `curious`, `thinking`, `sleepy`, `sleeping`, `wakeup`, `welcome`, `walk`, `run`, `jump`, `paw`, `stretch`

## 调度协议

AI 不直接操作文件路径，只返回动作 ID：

```json
{
  "type": "TANGTANG_ACTION",
  "action": "caring",
  "message": "起来走两分钟？",
  "priority": "normal"
}
```

播放器负责把 `action` 映射到具体媒体文件。

## 版本管理

GitHub 只保存正式、可复用的产品素材。临时生成图、个人家庭照片、声纹、语音缓存、运行时截图不进入仓库。
