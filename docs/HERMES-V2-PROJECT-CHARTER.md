# 糖糖 V2 项目章程：Hermes-Agent + Mac mini M6

> 状态：规划基线（第一阶段）
> 目标：在不破坏现有糖糖能力的前提下，将智能体引擎调整为 Hermes-Agent，并将家庭常驻运行环境迁移到 Mac mini M6。
> 当前阶段：架构审计与设计。本文档不代表已完成 Hermes 部署或 Mac mini 实机验收。

## 1. 项目目标

糖糖 V2 是家庭 AI 陪伴系统，不是把通用 Agent 换一个宠物形象。

- Hermes-Agent：智能体引擎，负责自然语言推理、任务规划、技能调用、工具编排及经验证可用的 Agent 能力。
- TangTang Core：产品与家庭业务核心，负责家庭成员、身份置信度、人格配置、家庭/私人记忆、隐私策略、儿童安全、主动陪伴决策和设备授权。
- Mac mini M6：家庭常驻主机，承载 Hermes、TangTang Core、本地语音/投影适配器及数据服务。
- 云端模型优先，本地模型按资源和体验评估后作为可选补充。
- OpenClaw 不再作为默认核心依赖；现有 OpenClaw 代码和配置先保留，只有明确的能力缺口经验证后才考虑外围接入。

## 2. 不可破坏的产品原则

1. 糖糖人格、家庭成员和安全策略由 TangTang Core 管理。
2. 未知身份不得自动绑定家庭成员；身份置信度不足时进入 unknown/澄清路径。
3. 儿童私人记忆默认不进入家庭共享记忆，也不得自动写入 Hermes 通用记忆。
4. 所有主动提醒先经过糖糖确定性策略，Agent 不得自行绕过安静时段、冷却时间和打扰规则。
5. Agent 输出是建议/结构化意图，不是系统命令；不得将自然语言或模型输出拼接执行 shell。
6. 家庭设备操作必须经过 TangTang Core 授权、目标设备校验和审计；敏感操作需要家长确认。
7. 生产数据、密钥、声纹、原始语音和儿童隐私不进入 Git。
8. 代码存在、单元测试通过、Mac 实机可用、投影端到端通过是不同验收层级，必须分别记录。

## 3. 范围与非目标

### 本项目范围
- Hermes 与 TangTang Core 的最小受控集成。
- Mac mini 原生运行环境和服务管理。
- 现有 V4 家庭大脑、记忆、人格、安全和陪伴能力保留。
- 语音、TTS、投影、主动陪伴和家庭设备功能分阶段恢复/接入。
- 自动化测试、实机验收、备份与回滚。

### 当前非目标
- 不重写现有 V4 家庭大脑。
- 不立即删除 OpenClaw 兼容代码。
- 不在第一阶段接入路由器写操作。
- 不把全部儿童对话交给 Hermes 持久记忆。
- 不因迁移而引入必须常驻的大型本地模型。
- 不在没有实机验证前宣称系统已可用。

## 4. 决策原则
1. 儿童安全、隐私和家庭权限。
2. 现有已验证产品行为与数据兼容。
3. 故障可隔离、可回滚、可审计。
4. 用户体验和运行稳定性。
5. 新 Agent 的功能先进性。

## 5. 当前基线与已知风险

- 本轮检查到 main 最新提交为 2026-10-29 的 7425e1e；实施前必须再次确认分支和提交。
- README 当前仍描述 MacBook Air 为运行设备。
- V4 接口模块将 CORE_API_VERSION 固定为 4.0.0；部分规划器文档出现 V5 字样，需先厘清版本口径，禁止擅自升级核心 API 主版本。
- 当前 V4 runtime 通过注入 LLM callable 接入模型，存在可作为 Agent Adapter 边界的基础，但不等于 Hermes 已集成。
- OpenClaw 历史部署报告描述的是旧硬件/旧 macOS 环境，不能直接推断 Mac mini M6 的部署结果。
- 当前开放 PR #67、#69、#70 均需重新审查；不得将未合并 PR 视为 main 已有功能。

## 6. 项目完成定义

只有同时满足以下条件，才可宣布 V2 达到家庭试运行：
- Hermes 与 TangTang Core 通过版本化、最小权限接口协作。
- 原有家庭成员隔离、隐私过滤、儿童安全及确定性打扰策略回归测试通过。
- 语音对话和投影链路在 Mac mini M6 实机通过。
- 主动陪伴具备去重、冷却、静默和失败恢复。
- 家庭设备写操作默认关闭，经过家长授权和实机验证后才可启用。
- 完成备份、恢复演练、运行监控和回滚验证。
- 连续运行验收达到项目标准，且所有未通过项透明列出。
