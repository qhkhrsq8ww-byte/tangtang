# 糖糖 V2 长期改造路线图

> 规划节奏：按阶段验收推进，不按日历强行赶工。
> 状态说明：未开始 / 进行中 / 待实测 / 已验收。当前全部实施阶段尚未验收。

## 总目标
Mac mini M6 + Hermes-Agent + TangTang Core。保留糖糖家庭大脑，以 Hermes 提升推理、技能和任务规划能力，逐步恢复完整家庭陪伴体验。

## 阶段总览

| 阶段 | 主题 | 预估节奏 | 状态 | 退出条件 |
|---|---|---:|---|---|
| 0 | 架构审计与基线冻结 | 1 周 | 基本完成（静态审计完成） | 静态资产审计、风险清单、接口决策完成；实机项转入阶段1 |
| 1 | Mac mini 与 Hermes 最小运行验证 | 1 周 | 未开始 | M6 对话、服务生命周期和资源监控通过 |
| 2 | Agent Adapter 最小集成 | 1–2 周 | 进行中（客户端骨架已合并） | 真实 Hermes API Server 联通、最小权限和安全回归通过 |
| 3 | 语音链路恢复 | 1–2 周 | 未开始 | STT→Core→Hermes→Core→TTS 端到端通过 |
| 4 | 投影与动作表现 | 1 周 | 未开始 | 语音、动作、视频同步，故障隔离通过 |
| 5 | 主动陪伴与记忆协作 | 1–2 周 | 未开始 | 去重、静默、冷却、隐私和调度验收 |
| 6 | 家长端与家庭设备只读接入 | 1–2 周 | 未开始 | 设备识别准确、保护设备、审计只读通过 |

时间是初步工作量估计，不是上线承诺；遇到安全或实机问题应延长阶段，不得跳过退出条件。

## 阶段 0：架构审计与基线冻结
任务：
- 再次读取 main 最新提交、CI 和开放 PR。
- 对 V4 运行时、身份、记忆、隐私、人格、陪伴、任务、语音、投影和设备模块建立资产清单。
- 查明 README 的 MacBook Air 运行口径、旧部署路径和 OpenClaw 依赖。
- 确认 `core/brain/planner.py` 的 V5 是规划器模块代际名称，不是 Core API V5；保持 CORE_API_VERSION=4.0.0。
- 对 Hermes 当前版本做官方文档核验和最小 PoC 设计。
- 明确 #67、#69、#70 的独立审查结论，不自动合并。

交付：代码资产审计、依赖和环境差异清单、Hermes 版本与接口验证报告、风险登记表、最小集成 ADR。

## 阶段 1：Mac mini 与 Hermes 最小运行验证
- 记录 M6 实际 macOS 版本、芯片、内存、磁盘可用空间。
- 原生安装 Hermes，锁定版本。
- 验证云端模型连通、认证、超时和成本控制。
- 验证 Gateway/CLI 生命周期、开机启动、单实例约束。
- 记录 CPU、内存、磁盘和日志增长。
- 不接真实家庭数据，不开路由器写权限。
退出条件：重启后服务可恢复；模型不可用时不会导致服务崩溃或无限重试。

## 阶段 2：Agent Adapter 最小集成
- 建立 Core 侧 Agent Port/Adapter。
- 先只开放获取本轮裁剪上下文和提交回复草稿。
- 接入 schema 校验、超时、请求过期、日志脱敏。
- 用合成家庭数据验证 unknown、PRIVATE、FAMILY 等场景。
- 完成安全测试后再增加提醒等工具。
退出条件：Agent 无法绕过 Core 读取任意记忆、执行 shell 或操作设备。

## 阶段 3：语音链路
- 盘点现有 STT、TTS、麦克风和音箱适配器。
- 分离设备采集与 Agent 推理。
- 支持打断、重复输入、无声、识别失败和网络超时。
- 测量首字响应、完整响应、TTS 播放延迟。
- 保留无云端模型时的安全 fallback。
退出条件：Mac mini 实机连续多轮对话通过，隐私策略不回退。

## 阶段 4：投影与动作
- 盘点现有视频/PNG 动作资源和投影控制。
- 将 action_id 映射到固定资源注册表。
- Agent 只能选择白名单 action_id，不返回文件路径或 shell。
- 验证音画同步、切换、休眠/唤醒和投影断连恢复。

## 阶段 5：主动陪伴与记忆协作
- 复用 CompanionPlanner、Speak Gate、Quiet Hours 和现有 TaskService。
- Hermes 可提出计划，Core 决定是否执行。
- 调度使用唯一权威来源，避免 Hermes Cron 与旧 crontab 重复触发。
- 对每个成员应用独立冷却、静默、优先级和去重键。
- Hermes 自动记忆默认关闭或严格 allowlist。
- 通过 Core 流程写入经确认的家庭记忆。
退出条件：重复提醒、越权记忆、错误身份和静默时段发声测试全部通过。

## 阶段 6：家长端与设备只读接入
- 先审查 PR #69/#70，按当前 main 重新基线化。
- 只读发现设备、标注 unknown、保护路由器和糖糖主机。
- 家长端核对设备归属。
- 不在此阶段执行断网、限速或写配置。

## 阶段 7：受控设备写操作
必须单独开 PR 和安全评审：
- 仅对家长确认的单台测试设备开放。
- 强制校验设备 MAC/ID、保护名单、授权有效期。
- 语音请求不得单独构成授权。
- 操作前显示目标和影响，家长确认后执行。
- 有审计记录、恢复/撤销路径和失败关闭策略。
- 禁止批量断网作为首发功能。

## 阶段 8：稳定性与切换
- 72 小时连续运行。
- 重启、断网、模型超时、TTS 失败、投影离线、磁盘空间不足等故障演练。
- 备份恢复演练。
- 确认旧 MacBook/旧 OpenClaw 路径的回退方案。
- 先影子运行，再小范围家庭试用，最后决定生产切换。

## 每周推进规则
1. 每轮只处理一个明确里程碑。
2. 开始前读取 main 最新状态，避免基于旧提交开发。
3. 每个改动单独分支和 PR。
4. 代码变更必须附测试；文档变更必须附证据链接或文件路径。
5. 未通过的检查明确标记待验证，不伪造验收结果。
6. 不自动合并 PR，不直接部署到家庭设备。
7. 每轮结束更新本路线图的状态、提交、PR、测试结果和下一步。
