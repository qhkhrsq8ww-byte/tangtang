# 糖糖形象设计要求与标准（V1.0）

> 状态：**当前形象不合格，需按本文件标准重新设计**
> 日期：2026-08-27
> 使用者：航航（9岁，小学三年级）
> 设备：MacBook Air + 大眼橙投影仪 + 小米蓝牙音箱

---

## 一、背景与问题

糖糖是陪伴 9 岁小朋友航航的 AI 宠物（比熊小狗形象）。当前形象经多轮 AI 生图迭代（SVG 手绘 + AI 文生图/图生图），用户反馈**「形象不行」**，需要重新设计。

当前已淘汰版本：
- v1-v4：手绘 SVG 比熊（识别度 5-6.5/10）
- AI 生图 base 版：可爱 8.5/10 但识别度 6.5/10
- AI 生图精修版：综合 8.4/10（曾定稿，但整体仍不满意）

---

## 二、糖糖形象总要求（一句话）

> **一看就是"白蓬松的比熊小狗"，二看就是"可爱到想抱"，三看就是"孩子一眼就喜欢"。**

三个优先级依次递减：**识别度 > 可爱度 > 精致度**。

## 三、形象标准（详细）

### 3.1 基本属性
| 项目 | 要求 |
|------|------|
| 物种 | 比熊犬（Bichon Frise），不是猫、不是柯基、不是博美 |
| 体型 | Q 版蛋形胖体，头身比接近 1:1.2，圆润饱满 |
| 毛色 | 奶油白为主，暖米黄阴影（非纯白，要有层次） |
| 毛发 | 卷毛质感（云朵状分层），蓬松、柔软、圆润 |
| 姿态 | 坐姿或站姿，短腿、圆屁股，尾巴卷翘 |

### 3.2 五官要求（严格）
| 部位 | 要求 |
|------|------|
| 眼睛 | 大而圆的黑眼珠，**三个高光点**（左上/右上/左下），占比脸 1/3，明亮有神 |
| 鼻子 | 纯黑或深棕近黑，心形或圆形，位于脸部中下方 |
| 嘴 | 微笑弧线，可含**粉色心形小舌**（吐舌更萌） |
| 耳朵 | **垂耳贴脸**（比熊特征），融于头部轮廓，不能竖立（竖立=像猫/柯基） |
| 腮红 | 淡粉，柔和，位于眼睛下方两侧 |
| 呆毛 | 头顶 2 根细咖色呆毛（可爱细节，加分项） |

### 3.3 配饰要求
| 项目 | 要求 |
|------|------|
| 项圈 | **金黄/橙色项圈**，带**圆角铭牌**，铭牌写「糖糖」或「Tangtang」或爪印 |
| 挂饰 | 可选粉色爱心/骨头小挂饰（加分项） |

### 3.4 色彩规范
- 主色：奶油白 #FFF8F0 ～ #FDF5E6
- 阴影：暖米黄 #F5E6C8 ～ #EFD9B0
- 鼻/眼：纯黑 #1A1A1A 或深棕 #3D2B1F
- 项圈：金黄 #FFB800 ～ #FFA000
- 腮红：淡粉 #FFB6C1
- 背景透明（PNG），可叠加任意背景

### 3.5 尺寸要求
- 主图：**1024x1024**（正方形，透明背景 PNG）
- 状态图：与主图同尺寸同构图，仅表情/姿态变化
- 文件格式：PNG（透明背景），单张 < 2MB

| 9 | sitting | 坐姿 |

## 五、最低交付标准（验收清单）

设计完成后必须逐项检查：

- [ ] 第一眼认出是比熊（不是猫/柯基/博美）
- [ ] 奶油白蓬松卷毛，有层次阴影
- [ ] 三高光大黑眼（占比 ≥ 1/3 脸）
- [ ] 纯黑/深棕圆鼻，粉色心形舌
- [ ] 垂耳贴脸，不竖立
- [ ] 金黄项圈 + 「糖糖」铭牌
- [ ] 透明背景 PNG，1024x1024
- [ ] 16 状态中至少 4 个关键状态（idle/happy/curious/sleeping）有独立图
- [ ] 表情变化通过"表情层"可叠加（眨眼/张嘴/Z字）

## 六、设计流程建议

1. **参考图**：优先使用用户提供的 3 张参考图（白色蓬松比熊、粉心舌、金黄项圈）
2. **AI 生图**：以参考图为 image2image 基底，逐项修正（耳朵/卷毛/鼻口）
3. **人工评审**：每版用 7 维评分表（见下）评审
4. **定稿标准**：识别度 ≥ 8/10 且 可爱度 ≥ 8/10 才算合格

### 评分表（7 维）
| 维度 | 权重 | 当前得分（参考） |
|------|------|------|
| 比熊识别度 | 30% | 6.5/10 ❌ |
| 可爱程度 | 25% | 8.5/10 ✅ |
| 形象一致性 | 15% | 7/10 |
| 颜色质感 | 10% | 8/10 |
| 配饰完整 | 10% | 7/10 |
| 状态可扩展性 | 5% | 6/10 |
| 儿童接受度 | 5% | 8/10 |
| **综合** | 100% | **7.2/10 ❌ 不合格** |

> 目标：综合 ≥ 8.5/10 且识别度 ≥ 8/10。

## 七、禁止事项（红线）

- ❌ 耳朵竖立（会像猫/柯基）
- ❌ 纯白无阴影（会像雪球/兔子）
- ❌ 黑色或深色毛（会像泰迪/雪纳瑞）
- ❌ 过于写实（会吓到孩子，要 Q 版卡通）
- ❌ 眼睛过小或表情凶狠
- ❌ 添加文字水印或品牌标识
- ❌ 身体部位分离（拼贴感，要整体感）
