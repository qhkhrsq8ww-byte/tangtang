# 糖糖 · 语音对话落地记录（2026-08-27 06:30）

## 目标
让糖糖"能听会说"——主人说话，糖糖听懂并用甜嗓回，无需打字。

## 链路与现状（4 段）
| 环节 | 状态 | 说明 |
|------|------|------|
| ① 录音（外置麦） | ✅ 通 | MAONO AU-BM10，ffmpeg 索引 `:1`，加 highpass+afftdn+volume=8 增益后稳定采声（峰值 -25dB vs 底噪 -74dB）|
| ② 语音转文字 STT | ⏳ 待填 key | 百度语音识别 REST API，脚本已写好，等用户填 API Key/Secret |
| ③ 云端 LLM 回话 | ✅ 通 | 复用 OpenClaw 网关 pool-deepseek-v4-pro，带记忆 |
| ④ 甜嗓 TTS 出声 | ✅ 通 | 百度 TTS 甜嗓（cat-say.sh cute 模式）|

## 关键结论（环境约束）
- **网关无 STT 接口**（audio/transcriptions 404），本机无 whisper（github 不通 + pip 老版本卡），无法本地 STT。
- **百度语音识别可行**：aip.baidubce.com 域名本机网络可达（403=需鉴权），与已用的百度 TTS 同家，风格统一。
- 外置麦音量一致性差（有时 -74dB 有时 -25dB）→ 已用自动增益/降噪函数稳定。

## 交付脚本
- `cat-listen.sh`：外置麦录音（带增益降噪），可指定秒数
- `cat-stt-config.sh`：**用户填百度 API Key / Secret 的位置**
- `cat-stt-baidu.sh`：调百度语音识别（自动拿 token + wav→pcm 16k）
- `cat-voice.sh`：统一语音对话入口（听→懂→答→说）

## 卡点修正（2026-08-27 19:20 实测）
- 领额度后仍 3305 → 排除限频。
- dev_pid=80001(极速版) 返回 3302 `No permission to access data` → 应用未开通极速版。
- 结论：**用户领的额度是『语音合成』(TTS，已能用)，而『语音识别ASR』服务这个应用未开通/未领额度**。
- 百度语音识别与语音合成是**两个独立服务**，需分别开通。

## 用户需做的一步（修正）
1. 打开 https://ai.baidu.com → 控制台 → 语音技术
2. 确认应用列表里『糖糖用的应用』已**添加『语音识别』服务**并领取其免费额度
   （之前只领了语音合成的额度，ASR 没开 → 一直 3305）
3. 若控制台无『语音识别』入口，需新建一个含 ASR 的应用，把新 key 填进 cat-stt-config.sh
4. 验证：`./cat-voice.sh`

## 用法
```bash
./cat-voice.sh          # 听5秒，自动对话
./cat-voice.sh 8        # 听8秒
```
