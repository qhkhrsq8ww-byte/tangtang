# 🐱 家庭陪伴猫「糖糖」方案

> 目标：用现有设备（Mac + 大眼橙 R3 Ultra 投影仪）养一只会说话、会提醒、会撒娇的家庭陪伴猫。
> 技术骨架：Mac=大脑（不关机）｜投影仪=脸（画面+喇叭）｜蓝牙=嘴（声音通道）

## 二、已验证的技术能力

### 0. 悬浮宠物页面（猫的脸·浮现版）✅
- `cat-pet.html`：透明背景糖糖，**浮在你看的内容之上**（配 AirPlay 镜像即实现「浮现」，不全屏占屏）。
- 特性：呼吸 / 眨眼 / 摇尾巴动画；说话冒对话泡；鼠标/触摸可拖动定位；点它撒娇。
- 轮询 `cat-mood.txt` → 统一入口/提醒说话时自动冒泡，无需刷新。
- 启动：`start-cat.sh`（起本地服务 + 开宠物页 + 弹镜像设置让你选投影）。

### 1. 语音（猫的嘴）✅ 已通 + 已变可爱（百度自然女声）
```bash
# 默认可爱甜嗓（百度翻译 TTS 自然中文女声，免费·无需token）
./cat-say.sh "小主人，我是糖糖，最喜欢你啦"
# 更快的播报
./cat-say.sh "..." fast
# 微软 Xiaoxiao 甜嗓（需网关通，失败自动回退）
./cat-say.sh "..." tts
# 系统机械嗓（纯离线备路）
./cat-say.sh "..." sys
```
- **主嗓：百度翻译 TTS 中文自然女声**（`cat-tts-baidu.mjs`，spd 1~7 可调，默认 4=慢柔可爱），本机网络可达。
- 离线备路：`say -v Ting-Ting [[rate 150]][[pitch 118]]` 机械但绝不失败。
- 进阶甜嗓：`cat-tts.mjs` 微软 XiaoxiaoNeural（真·甜女声），网关需 Sec-MS-GEC 校验，本机对 g.pe 不可达暂返 403；脚本已就绪。
- 声音经蓝牙 → 投影仪喇叭（OBE_R3Ultra1501，已配对连接）。

### 2. 投影仪蓝牙身份
- Advanced Audio Sink（音频接收）✅ → 能当音箱
- AV Remote Control Target → 可被遥控
- Advanced Audio Source → 也能输出声音

### 3. 投影仪画面（悬浮 + 镜像，不依赖 ADB）
- 投影仪 AirPlay 服务在端口 61949，标准接收端，Mac 可屏幕镜像。
- 选「OBE_R3Ultra 旗舰版(OBE)501」镜像 → 透明宠物页浮在投影画面之上。
- 无需开 ADB（沙发管家后门已证无效，ADB 被大眼橙藏死）。

## 三、猫咪功能（按优先级）

### 🥇 核心功能 1：悬浮陪伴宠物（浮现）✅ 已完成
- 文件：`cat-pet.html`（透明背景、呼吸/眨眼/摇尾、对话泡、可拖动、点击撒娇）
- 用法：`./start-cat.sh` → 投影开镜像选 OBE_R3Ultra(OBE)501 → 糖糖浮现在角落
- 触发说话：`./cat.sh "想说的话"` / `cat-remind.sh`（定时自动冒泡+出声）
- 备选：`./cat.sh -s` 全屏大脸模式（不想要浮现时）

### 🥈 核心功能 2：定时提醒（语音播报）
猫在固定时间用语音提醒：
- 晚 8 点后每 40 分钟：「该休息眼睛啦，喵～」
- 睡觉点：「小主人，该睡觉啦」
- 可扩展：叫早、吃药提醒、喝水提醒
**实现**：cron 定时 → 调 cat-remind.sh → cat-say.sh 出声（已装 2 条）。

### 🥉 核心功能 3：陪聊解闷（轻量版）
你说一句，猫回一句（百度甜嗓 + 投影冒泡）。
- 轻量版：预设问答库（不用联网，4GB 内存扛得住）。
- 进阶版：接入大模型 API（需要联网+API key）。
