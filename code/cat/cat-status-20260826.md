## 重大转机：Mac AirPlay 直接镜像（绕过 ADB）✅
- 用户建议：别控制投影仪，直接 Mac 投屏。完全正确！
- 局域网扫描发现投影仪暴露 `_airplay._tcp` 服务：
  - `OBE_R3Ultra 旗舰版(OBE)501` / `(OBE)060`，端口 61949（Android-3.local.）
  - model=AppleTV3,1，features 全开 → 标准 AirPlay 接收端
- **结论：Mac 用系统「屏幕镜像」即可把猫脸投上投影，无需 ADB/开发者选项/控制投影**。
- 脚本 `cat/cat-screen.sh`：起本地猫脸服务 + 打开网页 + 弹显示器设置 + 猫语音提示。
- 实测：猫脸页 HTTP 200，投影 AirPlay 端口 61949 可达。
