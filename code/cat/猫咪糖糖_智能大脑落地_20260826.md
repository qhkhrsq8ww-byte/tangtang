# 糖糖 · 智能大脑 v2.0 落地记录（2026-08-26 23:05）

## 一句话
把「会说话冒泡的图片」升级为「有性格、有情绪、有记忆、会主动」的陪伴宠物大脑。

## 本阶段新增（离线规则引擎，4GB 内存友好，不联网不常驻）

### 1. 大脑引擎 `cat-brain.py`（核心）
- **情绪状态机**：开心/精力/想念/亲密度 4 维度（0-100），随时间漂移、随事件增减。
  - 距上次互动越久 → 想念↑、开心回落；深夜 → 犯困。
- **记忆持久化**：`cat-state.json`（情绪+今日计数）、`cat-memory.json`（昵称/初见日/累计互动）。
- **决策话术库**：温柔粘人奶牛猫「糖糖」人设，按心情标签（happy/calm/lonely/sleepy/low）给不同反应。
- **亲密度系统**：亲密度≥80 时说话更亲昵（自动追加"最喜欢你啦"）。

### 2. 交互入口 `cat-talk.sh`
- 事件驱动：`greet/wake/sleep/rest/meal/pat/home/random/say/status`
- 大脑定话术+情绪 → **按情绪选音色**（开心快/困拖长/想念更柔）→ 写画面气泡 → 出声。

### 3. `cat.sh` 升级
- 默认说话改走大脑（不再是写死模板），新增 `status` 查看心情。

### 4. `cat-remind.sh` 改事件驱动
- 事件：rest/sleep/wake/meal(lunch|dinner)/random/home

### 5. 主动陪伴时刻表（crontab，6 条）
| 时间 | 事件 | 说明 |
|------|------|------|
| 07:30 | wake | 早安 |
| 12:00 | meal lunch | 午饭关怀 |
| 15:00 | random | 随机撒娇（约60%开口） |
| 18:30 | meal dinner | 晚饭关怀 |
| 20-21点每40分 | rest | 久坐休息提醒 |
| 22:30 | sleep | 晚安 |
