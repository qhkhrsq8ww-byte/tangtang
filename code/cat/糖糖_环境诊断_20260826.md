## 二、内存压力实况（跑"智能"的墙）

- 总 4GB，空闲+可回收 **约 1.2GB**。
- 内存大户：QClaw 图形进程 ~737MB + openclaw 主进程 ~673MB，已吃掉约 1.4GB。
- **结论**：本地跑 LLM（需 4-8GB+）或本地 Whisper（需 2-4GB）都会直接 OOM/被 SIGTERM。此前 Claude Code 安装失败（需 macOS 13+）、Whisper 方案放弃，都是同一堵墙。

## 四、三条升级路径

### 方案 A · 云端智能（零硬件成本，最务实 ✅ 推荐）
把"大脑"搬到云端，本地只做轻编排：
- **对话 LLM**：接云端 API（DeepSeek / 通义千问 / GLM，按 token 付费，很便宜）
- **TTS**：已在用百度免费女声；可换微软 edge-tts 真甜嗓
- **ASR 语音识别**：在线 API（阿里/讯飞/Whisper 云）
- 优点：4GB 完全够用、效果最好、糖糖能真聊天
- 缺点：要联网、有 token 费用（但月成本通常几块钱到几十块）

### 方案 B · 换机（治本，一次性投入）
- 4GB 焊死不可升级，只能换机。
- 二手 M1/M2 Mac mini 或 8GB+ 笔记本（约 1500-3000 元）。
- 换机后可跑本地小模型（llama.cpp 7B 量化）+ 本地 Whisper，彻底离线。

### 方案 C · 软件瘦身（缓解，不治本）
- 关 QClaw 图形窗口 → 释放 ~700MB。
- 清后台 edge-tts pip、定期清 Cache。
- 只能让现有脚本跑得更稳，无法让"智能"上台阶。
