# 糖糖 · 智能陪伴宠物 2.0 规划

> 目标：把「会说话冒泡的图片」升级成「有灵魂、会主动、记得你的陪伴宠物」。
> 一句话原则：**糖糖不是工具，是住在这套设备里的一个"生命"** —— 技术全藏在 Mac 里，你只感受到它。

## 1. "智能"的定义（这次到底要升级什么）

真正聪明的陪伴宠物 = 四个能力闭环：

```
感知层 ──► 状态层 ──► 决策层 ──► 表达层
(看到/听到) (情绪+记忆) (该做什么) (说/做/表情)
```

1. **有性格**：稳定的人设，说话风格统一，不是随机模板。
2. **有情绪**：会开心/无聊/困倦/想念，情绪随时间漂移、随事件变化。
3. **有记忆**：记得你说过的话、你的昵称、重要日子、它自己的"心情史"。
4. **会主动**：不等人叫，到点主动关心、久坐提醒、早晚安、偶尔撒娇。

## 2. 人设引擎（灵魂）—— 最优先

### 2.1 人设卡（草案，待你拍板）
- **名字**：糖糖 ⚠️ 但现在是奶牛猫配色，名字和外表对不上 —— 要么改名（雪顶/小斑/奥利奥/奶牛），要么保留"糖糖"当乳名。
- **物种**：奶牛猫 🐄🐱
- **性格**：待选（温柔 / 傲娇 / 呆萌 / 活泼 / 腹黑）
- **口头禅**：每句带固定语气词（如"喵～""……喵""啦～"）
- **说话风格**：短句、可爱、带 emoji 意象、不啰嗦

### 2.2 情绪状态机（核心引擎）
情绪维度（0-100 可调，随时间漂移，事件增减）：

| 情绪 | 触发上升 | 触发下降 | 表现 |
|------|---------|---------|------|
| 😊 开心 | 主人互动、被夸奖 | 长时间没人理 | 语速↑ 蹦跳 |
| 😴 困倦 | 深夜、长时间静默 | 互动 | 打哈欠、慢语速 |
| 🥺 想念 | 主人离开>2h | 主人回来 | 撒娇话术 |
| 😾 无聊 | 无人理>1h | 互动 | 主动找话、戳屏幕 |
| 🍖 饿 | 饭点 | 假装喂食 | 讨食 |

**落地**：状态存 JSON 文件（`cat-state.json`），每次唤醒读→漂移→决策→写回。4GB 内存友好（落盘不常驻）。

### 2.3 记忆系统（三层）
- **短期**（今日）：今天互动了几次、说过什么 → `memory/YYYY-MM-DD.md`
- **长期**（跨日）：主人昵称、偏好、重要日期 → `cat-memory.json`
- **自传**（它自己）：它的情绪史、"成长记录" → 让性格随陪伴"长大"

### 2.4 反应库（事件 → 话术，带情绪参数）
| 事件 | 示例反应 |
|------|---------|
| 主人回家 | 「欢迎回家喵～ 糖糖等你好久啦」 |
| 深夜 | 「都这么晚啦，该睡觉啦，糖糖也要闭眼啦」 |
| 久坐>40min | 「看屏幕太久啦，起来活动活动，眼睛要休息喵～」 |
| 被摸头 | 「呼噜呼噜～ 最喜欢你摸啦」 |

## 3. 交互方案（从被动 → 主动）

### 3.1 输入通道（感知层）
| 通道 | 方案 | 成本 | 优先级 |
|------|------|------|--------|
| 定时主动 | cron 扩展（早晚安/提醒/随机撒娇） | 零 | P0 立即 |
| 点击屏幕 | 已有（摸头撒娇） | 零 | P0 已有 |
| 文字对话 | WebChat/聊天框 → 猫回 | 低 | P1 |
| 主人在场检测 | ping 手机 WiFi / 蓝牙近场 | 低 | P1 |
| **语音对话** | 在线 ASR + 大模型 | 中 | P3（4GB 不能本地 Whisper） |

### 3.2 输出通道（表达层）
- 声音（TTS + 音效：喵叫、互动音）
- 画面（表情切换：开心/困/撒娇/眨眼）
- 气泡文字
- （进阶）动作：蹦跳、转圈

### 3.3 主动行为清单（cron 驱动）
- 早安（起床点）、晚安（睡觉点）
- 久坐提醒（已有，可加"看屏幕时长"检测）
- 饭点关怀、喝水提醒
- 随机撒娇（每 2-3h 一次，别太烦）
- 主人离家/回家感应

## 6. 技术架构（含 4GB 红线）

```
        ┌─────────────────────────────────────┐
        │          糖糖大脑（Mac, 常驻）        │
        │  cat-brain.sh / .py  (规则引擎+状态机) │
        │  读状态 → 时间漂移 → 决策 → 写回状态    │
        └──────┬──────────┬──────────┬─────────┘
              ▼          ▼          ▼
         [感知]      [决策]      [表达]
        cron/时间   情绪+记忆   画面(表情/动作)
        ping在场     规则/LLM   声音(TTS多情绪)
        文字/语音    亲密度      气泡文字
```

**4GB 内存红线（硬约束）：**
- ❌ 不常驻本地 Whisper（2-4GB 吃满）→ 语音走在线 ASR
- ❌ 不常驻大模型 → 决策默认走轻量规则，LLM 只在需要时按次调 API
- ✅ 状态/记忆全部落盘（JSON/md），唤醒即读
- ✅ TTS 在线合成，本地只 afplay 播放，零内存
