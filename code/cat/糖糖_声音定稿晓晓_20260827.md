# 糖糖声音定稿：微软晓晓（XiaoxiaoNeural）

**决策时间：** 2026-08-27 21:49 GMT+8  
**选择：** 1号候选人——微软神经语音「晓晓」（zh-CN-XiaoxiaoNeural）

## 声音标准（来自 `04-糖糖AI声音设计说明书-V1.0.md`）

> **不是**萝莉音 / 不是娃娃音 / 不是客服音 / 不是播音腔  
> **而是**：年轻女性 + 温柔 + 明亮 + 微笑感 + 轻微童趣 + 自然口语  
> **第一标准是"耐听"（听 100 次不烦），第二才是"可爱"**

## 候选对比

| 编号 | 音色 | 特点 | 结果 |
|------|------|------|------|
| 1 | **晓晓 XiaoxiaoNeural** | 温暖女声 | ✅ **定稿** |
| 2 | 晓伊 XiaoyiNeural | 活泼女声 | 备选 |
| 3 | 晓北 XiaobeiNeural | 东北方言 | 口音太重 |
| 4 | 晓妮 XiaoniNeural | 陕西方言 | 口音太重 |
| 5 | 度小萌（百度） | 童声 | 不符合"年轻女性"定位 |
| 6 | 其他百度音色 | 免费但质感有限 | 不够自然 |

## 最终参数（符合声音标准）

- **默认：** 语速 -10%（90% 正常速度）、音高 +5Hz（略高于普通女性）
- **开心/欢迎：** 语速 +5%（略快）、音高 +8Hz（明亮）
- **困/睡觉：** 语速 -20%（慢柔）、音高 +3Hz（柔和）
- **想念/关心：** 语速 -15%（温暖）、音高 +5Hz（亲切）

## 已接入文件

- `cat-tts-edge.py`：晓晓封装脚本（带参数转换）
- `cat-say.sh`：通用说话入口（默认晓晓，百度翻译 TTS 回退）
- `cat-talk.sh`：大脑情绪→音色映射（晓晓 + 回退链）
- crontab 12 条定时提醒（自动调用晓晓）

## 回退链

```

```
