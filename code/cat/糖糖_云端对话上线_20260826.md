# 糖糖 · 云端智能对话上线记录（2026-08-26 23:20）

## 目标
给陪伴宠物「糖糖」（奶牛猫，原"小橘"已更名）接上**真正的对话智能**——不再写死话术，能自由聊天、有记忆。

## 核心结论
**零新增依赖、零额外费用**：复用 OpenClaw 自带的 LLM 网关，无需用户另买 API key。

## 关键发现（踩坑记录，重要）

### 1. 本机已内置 LLM 网关
- 环境变量 `QCLAW_LLM_BASE_URL=http://127.0.0.1:19000/proxy/llm`（OpenAI 兼容）
- `QCLAW_LLM_API_KEY` 在子进程里是**托管占位符** `__QCLAW_AUTH_GATEWAY_MANAGED__`（真实密钥不暴露，网关转发时替换）
- `/models` 返回 **11 个模型**：modelroute(Auto)/pool-deepseek-v4-pro/flash/pool-glm-5.2 系列/pool-kimi-k2.7 系列/pool-minimax-m3 系列

### 2. 三个坑（都踩过、都解决）
| 坑 | 现象 | 解法 |
|----|------|------|
| **模型名** | `qclaw/pool-deepseek-v4-pro` 报 `model_not_valid` | 用 `pool-deepseek-v4-pro`（不带 `qclaw/` 前缀） |
| **max_tokens 太小** | 回复退化成"原样重复用户输入" | 该模型带 `reasoning_content`(思考链)吃 token，调到 600+ |
| **缺 User-Agent 头** | urllib 发请求 400 `invalid request`，curl 却 200 | **必须带 `User-Agent` 头**（任意值），否则网关 400 |

### 3. 对话质量验证（真实输出）
- 「主人今天工作好累」→「主人辛苦啦～要不要糖糖帮你踩踩背喵～」
- 追问「怎么安慰我」→「糖糖会蹭蹭主人的腿，再用尾巴轻轻圈住你的手腕…喵～」
- 「我刚才说我怎么了」→「主人刚才说今天工作好累呀，糖糖都有记在心里喵～」（**有跨轮记忆** ✅）
