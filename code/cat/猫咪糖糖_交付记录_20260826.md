## 配色切换：橘猫 → 奶牛猫（2026-08-26 22:37）

### 用户需求
> 「奶牛猫吧」

### 改动（4 版迭代，图像评审 8.5/10 定稿）
- 配色：暖橘 → **白底黑斑**奶牛猫；粉鼻/腮红/蝴蝶结/肉垫保留做暖色呼应。
- 黑斑用 `clipPath` 锁在头/身轮廓内不溢出。
- 斑点分布：左耳根不规则锯齿斑 + 右脸小斑 + 背部 2~3 块不规则斑块 + 整条黑尾（奶牛猫特征）。
- 五官（镜像对称大眼、W 嘴、肉垫）全部保留。

| 版本 | 关键改动 | 评分 |
