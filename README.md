# 糖糖 AI（TangTang AI）

> 一只住在投影里的比熊小狗。

## 当前阶段

**V1：Mac 投影动画系统**

第一阶段只解决一个问题：让糖糖真正“活起来”。

### V1 目标

- 糖糖待机呼吸
- 眨眼
- 轻微歪头
- 耳朵/尾巴自然运动
- 开心
- 好奇
- 困倦
- 睡觉
- 起床
- 欢迎
- 陪伴/提醒
- 散步/行走
- 全屏投影模式
- Animation Lab 动画测试实验室
- 为未来 OpenClaw 控制预留本地 API

## 产品原则

> AI 决定“糖糖现在应该做什么”，动画引擎决定“糖糖具体怎么动”。

不要把整张 PNG 简单平移、缩放或旋转后称为角色动画。目标是让糖糖看起来像一只真正有生命感的小狗。

## 当前硬件设想

- MacBook Air：运行糖糖程序
- 大眼橙投影：显示糖糖
- HDMI 1：游戏机等其他视频源
- HDMI 2：MacBook Air

第一阶段暂不开发 HDMI 自动切换。

## 开发方式

采用“文档 → Issue → 开发 → Mac 实机测试 → 修改”的迭代方式。

每完成一个动画，都必须实际运行验证自然度，而不是只检查代码是否存在。
